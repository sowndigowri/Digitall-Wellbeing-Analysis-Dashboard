📊 Digital Wellbeing Analysis Dashboard

A data analytics project designed to analyze digital behavior, screen time, app usage, distraction patterns, and digital wellbeing using Excel, MySQL, and Power BI.

The dashboard helps identify the major factors contributing to digital distraction and provides insights that can support healthier and more productive digital habits.

🎯 Project Objective

The main objective of this project is to understand how users interact with digital devices and identify patterns that may contribute to distraction and reduced digital wellbeing.

The analysis focuses on:

Screen time and social media usage
App usage patterns
Distraction levels
Content consumption
Time-based distraction
Location-based distraction
Burnout risk
Overall digital wellbeing
🛠️ Technologies Used
Excel – Data cleaning and preprocessing
MySQL – Data storage, querying, and analysis
Power BI – Dashboard development and data visualization
Power Query – Data transformation and preparation
DAX – KPI and analytical measure creation

🔍 Key Insights
Average daily screen time is approximately 6.55 hours.
Entertainment has the highest distraction score at approximately 4.53.
Social Media follows closely with a distraction score of approximately 4.49.
Afternoon shows the highest distraction level among the analyzed time periods.
Users categorized with high burnout risk show higher distraction scores than low-risk users.
College and library environments show relatively high distraction levels.
High screen time does not always mean high distraction because productive applications can also contribute to total screen usage.

🎯 Project Outcome

The project demonstrates how data analytics can be used to move beyond simply measuring screen time and instead understand when, where, and how digital distraction occurs.

The ultimate goal is to distinguish between productive and distracting digital usage and support users in developing healthier digital habits.
