# AWARE AI – Digital Wellbeing Analysis Platform

## Project Overview

AWARE AI – Digital Wellbeing Analysis Platform is a Power BI-based data analytics project designed to analyze digital usage behavior, identify distraction patterns, and understand wellbeing-related indicators.

The project provides a detailed view of digital activity by analyzing application usage, usage duration, keywords, content categories, time of day, user groups, sleep, and wellbeing indicators.

## Problem Statement

Traditional screen-time analysis mainly shows how much time a person spends on a digital device.

However, screen time alone does not explain:

- Which applications contribute to usage
- Which content categories receive more attention
- Which keywords are associated with distraction
- When digital activity occurs
- How digital behavior differs across user groups
- How usage patterns relate to sleep and wellbeing indicators

This project addresses these areas through an interactive Power BI dashboard.

## Objectives

- Analyze digital usage behavior
- Analyze application usage patterns
- Identify distraction patterns
- Analyze keywords and content categories
- Compare distraction across different times of day
- Compare digital behavior across user groups
- Analyze sleep and wellbeing indicators
- Present the findings through an interactive Power BI dashboard

## Dashboard Pages

### 1. Introduction

Provides an overview of the AWARE AI project and its purpose.

### 2. Executive Overview

Provides a high-level view of digital usage, screen time, application usage, distraction patterns, keywords, and content categories.

### 3. Distraction Intelligence

Focuses on distraction-related patterns across applications, keywords, content categories, time of day, and burnout-risk groups.

### 4. Wellbeing & User Insights

Focuses on screen time, user groups, sleep indicators, wellbeing indicators, and wellbeing distribution.

## Project Outcome

The final Power BI dashboard transforms prepared data into interactive visualizations and analytical insights about digital behavior, distraction, and wellbeing.

The project demonstrates an end-to-end data analytics workflow from data preparation to dashboard development.
